# Portfolio

Personal portfolio site for Ruth Sirma, built with React + Vite.

All pages are currently under development.

## Getting started

```bash
pnpm install
pnpm dev      # start the dev server
pnpm build    # production build into dist/
pnpm preview  # preview the production build
```

## Structure

- `src/components/Layout.jsx` — header, navigation, footer shell
- `src/components/UnderDevelopment.jsx` — placeholder page
- `src/App.jsx` — routes (About, Resume, Projects, Contact)
